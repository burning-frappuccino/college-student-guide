# 2026大学生评价指南 · V2

这是一个纯前端、零登录、零后端、零 AI API 的可运行原型。

## 快速运行

直接打开 `index.html` 即可。

推荐使用任意静态服务器运行，例如：

```bash
npx serve .
```

然后访问：

`http://localhost:8000`

## 免费公网发布

项目是纯静态前端，可以直接发布到 GitHub Pages，不需要自建后台：

1. 新建一个 GitHub 仓库。
2. 将本目录内的文件上传到仓库根目录。
3. 打开仓库的 Settings → Pages。
4. Source 选择 Deploy from a branch。
5. Branch 选择 main，目录选择 /(root)，保存。

发布完成后可通过以下形式访问：

`https://你的用户名.github.io/仓库名/`

页面首次联网打开后会缓存核心文件，之后可在离线状态下再次打开。

## 真实人数统计

项目已预留 GA4 访问与完成事件。按照 `ANALYTICS.md` 填入 Measurement ID 后，可以查看访问人数、开始次数、完成次数、完成率和分享下载次数。

统计不会上传用户的具体选项。

## 项目结构

- `index.html`：入口
- `style.css`：Cyber Lab 视觉
- `app.js`：测试流程与结果页
- `questions.js`：20 道具体生活场景题
- `scoring.js`：评分算法
- `copy.js`：结果文案
- `stats.js`：统计预留及演示数据
- `PRD.md`：完整产品需求
- `CLAUDE_PROMPT.md`：可以直接交给 Claude Code 的开发指令

## 重要说明

当前群体统计使用的是**演示数据**，不能当作真实人群统计。

正式上线后，如果需要统计，应只使用匿名聚合数据，并明确样本量与统计口径。

## V1 原则

- 不登录
- 不注册
- 不收集手机号/邮箱
- 不依赖 AI API
- 不依赖数据库
- 不讨论院校、学历、出身或政治立场
- 保留 AI 生产力评价，但不把使用时长直接等同于能力
- 娱乐类型不决定分数，主要观察无意识时间是否挤压现实生活
